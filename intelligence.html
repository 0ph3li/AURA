Four ways of thinking.

Different questions call for different kinds of attention. Aura switches between them on its own.

Works the problem, not just the prompt.

Aura breaks a hard question into smaller checks, follows each one, and drops the ones that don't hold up — instead of committing to the first plausible answer.

Drafts wide before it narrows.

For open-ended work, Aura sketches a few real directions before committing to one — so the first version you see isn't the only one it considered.

Remembers what mattered, not everything.

Aura keeps the details that shape your next answer — a preference, a constraint, a decision already made — and lets the rest fade the way a good conversation should.

Reads a picture like it reads a sentence.

A screenshot, a whiteboard photo, a page of handwriting — Aura pulls out the structure first, then answers about what's actually there.

One mind, many senses.

Flip a card to see how Aura treats each kind of input differently.

Text

Conversation, writing, code

Reads for intent first — a question, a request, a vent — and matches its tone and depth to which one it actually is.

Code

Reading, writing, debugging

Traces execution paths, not just syntax — so a fix addresses the assumption that broke, not just the line that crashed.

Vision

Photos, screenshots, diagrams

Separates structure from content first — a chart's axes before its numbers, a UI's layout before its labels.

Audio

Voice, tone, pacing

Picks up hesitation and emphasis, not just words — the difference between "sure" meant plainly and "sure" meant reluctantly.
