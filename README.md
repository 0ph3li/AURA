Aura is a concept website for a fictional AI assistant, one that reasons out loud, remembers what your work needs and stays on your device whenever it can. The site is designed with the same restraint as the product it presents: one typeface, four colors, an 8px grid and motion only when something changes.

🔗 **Live site:** https://0ph3li.github.io/AURA/

> *"Hello! :) I'm Aura. Intelligence, without the noise."*

---

## ✦ Pages

| Page | Description |
|------|-------------|
| `index.html` | Home: intro, product overview and quick questions |
| `intelligence.html` | How Aura thinks: reasoning, creativity, memory and vision, shown step by step |
| `design.html` | The Aura design system: type, color, space and motion |
| `privacy.html` | How data stays on-device, is encrypted and is deleted |
| `pricing.html` | Plans (Free, Pro, Studio) with a quiz that suggests the right one |
| `plans.html` | Full feature comparison between plans |

## ✦ Interactive features

- **Animated 3D wireframe orb** (`wireorb.js`), hand-built with the Canvas API and manual 3D projection, no libraries
- **Live reasoning demo:** watch Aura work through a problem in steps
- **Type playground:** change weight, size and tracking in real time
- **Color palette:** click a swatch to copy its hex code
- **Privacy slider:** see how much is handled on-device vs. in the cloud
- **Encryption demo:** type a message and see what actually travels
- **Plan finder quiz** and monthly / yearly billing toggle
